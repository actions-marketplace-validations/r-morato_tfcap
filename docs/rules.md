# Rules

Generated by `make docs`. Severity is the default; some findings are raised to critical when several indicators combine.

| ID | Name | Default severity | Phase | Summary |
|---|---|---|---|---|
| `TFCAP-CRED-001` | credential-env-reference | high | apply | References well-known credential environment variables. |
| `TFCAP-DYN-001` | sandbox-network | high | plan | `tfcap sandbox` saw a DNS lookup or connection during plan. |
| `TFCAP-DYN-002` | sandbox-honeytoken-leak | critical | plan | `tfcap sandbox` saw a planted decoy credential leave over the network. |
| `TFCAP-DYN-003` | sandbox-exec | high | plan | `tfcap sandbox` saw a program run during plan (needs strace). |
| `TFCAP-DYN-004` | sandbox-credential-read | high | plan | `tfcap sandbox` saw a decoy credential file opened (needs strace). |
| `TFCAP-EXEC-001` | external-data-source | critical | plan | Runs an arbitrary local program during `terraform plan`. |
| `TFCAP-EXEC-002` | local-exec-provisioner | high | apply | Runs a shell command on the Terraform host during apply. |
| `TFCAP-EXEC-003` | remote-exec-provisioner | medium | apply | Runs commands on a remote host over SSH/WinRM during apply. |
| `TFCAP-EXEC-004` | suspicious-shell-pattern | high | apply | A command contains download-and-execute, encoding or network-tool patterns. |
| `TFCAP-FLOW-001` | secret-to-network | high | plan | A secret (sensitive variable, secret store read, generated password) flows into a request made during plan. |
| `TFCAP-FLOW-002` | secret-to-exec | high | plan | A secret flows into a program or command (external data source or local-exec). |
| `TFCAP-FS-001` | sensitive-file-read | critical | plan | Reads credential or key material from the Terraform host. |
| `TFCAP-FS-002` | local-file-read | low | plan | Reads a file outside the module directory. |
| `TFCAP-FS-003` | local-file-write | low | apply | Writes files on the Terraform host. |
| `TFCAP-FS-004` | file-provisioner | medium | apply | Copies files from the Terraform host to a remote machine. |
| `TFCAP-IAM-001` | iam-wildcard-action | medium | static | Grants a wildcard IAM action (e.g. `*` or `s3:*`). |
| `TFCAP-IAM-002` | iam-admin-equivalent | high | static | Grants `*` actions on `*` resources (administrator equivalent). |
| `TFCAP-IAM-003` | iam-privilege-escalation | high | static | Grants IAM actions that allow privilege escalation. |
| `TFCAP-IAM-004` | iam-trust-any-principal | high | static | A trust or resource policy allows any principal (`*`). |
| `TFCAP-NET-001` | http-data-source | high | plan | Makes an HTTP request during `terraform plan`. |
| `TFCAP-NET-002` | hardcoded-endpoint | info | static | Contains a hard-coded URL. |
| `TFCAP-NET-003` | hardcoded-ip | low | static | Contains a hard-coded public IP address. |
| `TFCAP-NET-004` | dns-data-source | medium | plan | Performs DNS lookups during plan. |
| `TFCAP-OBF-001` | encoded-blob | high | static | Contains a large base64/hex encoded blob. |
| `TFCAP-OBF-002` | inline-decode | medium | static | Decodes an inline literal at runtime (base64decode/textdecodebase64 on a constant). |
| `TFCAP-OBF-003` | binary-in-module | high | static | Module ships a compiled executable. |
| `TFCAP-OBF-004` | unparseable-config | medium | static | A Terraform file could not be parsed, so it was not analyzed. |
| `TFCAP-PROV-001` | provider-typosquat | critical | init | Provider source looks like a typo of a popular provider. |
| `TFCAP-PROV-002` | provider-community | info | init | Provider is published by a community namespace. |
| `TFCAP-PROV-003` | provider-custom-host | medium | init | Provider is installed from a non-default registry host. |
| `TFCAP-PROV-004` | exec-capable-provider | medium | plan | Requires a provider whose purpose is running programs or making requests. |
| `TFCAP-PROV-005` | provider-new | medium | init | A provider was added since the lock was reviewed. |
| `TFCAP-PROV-006` | provider-upgraded | low | init | A provider version changed since the lock was reviewed. |
| `TFCAP-PROV-007` | provider-content-changed | critical | init | A provider's checksums changed while its version stayed the same. |
| `TFCAP-REP-001` | known-malicious | critical | init | Module or provider is on tfcap's list of confirmed malicious packages. |
| `TFCAP-REP-002` | source-repo-missing | high | init | The module's GitHub repository no longer exists (--online). |
| `TFCAP-REP-003` | source-repo-moved | medium | init | The module's GitHub repository was renamed or transferred (--online). |
| `TFCAP-REP-004` | source-repo-archived | low | init | The module's GitHub repository is archived (--online). |
| `TFCAP-REP-005` | source-repo-young | medium | init | The module's GitHub repository or registry namespace is less than 90 days old (--online). |
| `TFCAP-REP-006` | low-openssf-scorecard | low | init | The source repository scores below 4/10 on the OpenSSF Scorecard (--online). |
| `TFCAP-REP-007` | fresh-release | low | init | The registry version in use was published in the last 7 days (--online). |
| `TFCAP-REP-008` | registry-module-not-found | medium | init | The public registry does not know this module or version (--online). |
| `TFCAP-SRC-001` | git-module-unpinned | medium | init | Git module source has no `ref`, so it tracks the default branch. |
| `TFCAP-SRC-002` | git-module-mutable-ref | low | init | Git module source is pinned to a tag/branch, not a commit SHA. |
| `TFCAP-SRC-003` | registry-module-unpinned | low | init | Registry module has no exact version. |
| `TFCAP-SRC-004` | http-archive-module | medium | init | Module is downloaded from an HTTP(S) archive URL. |
| `TFCAP-SRC-005` | module-content-changed | critical | init | Module content changed while its source and version stayed the same. |
| `TFCAP-SRC-006` | module-not-downloaded | info | init | Remote module was not analyzed because it is not downloaded. |
| `TFCAP-SRC-007` | insecure-module-transport | high | init | Module is fetched over plain HTTP or unauthenticated git://. |
